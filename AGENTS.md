# Project conventions

- Keep Impact reporting values in `src/data/impact.json` with focused tests so published news milestones remain verifiable.
- Keep new images in the project asset directory, use original organization photography where available, and optimize files for the web.
- Home owns the Programs section; redirect `/programs` to `/#programs` to preserve old links without keeping a duplicate page.
- Scope the uploaded home reference palette to `.home-theme` so all other pages retain their existing presentation.
- Home highlight metrics read the shared Impact data to remain consistent with news reporting.
